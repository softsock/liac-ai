# Conversation research clients

Keep Qt out of this package. LabHost owns the real Runtime, archive and output
fan-out; SimulationController receives only a submit callable and public text.
Never pass Journal, Markdown context, Deep proposals or diagnostics to the human
simulator. Its OMP session, role, workspace and history are independent of Luna.

Run archives are private, ignored observations, not another domain Journal.
Replay never creates providers. Preserve source IDs, captured snapshots, gaps,
cancelled partial output and provenance; never substitute current state for
missing historical context. One owner per run; continuation is explicit.

Trace disk writes stay off the inference loop. Bound queues, previews and capture;
surface omissions. Cost/cache data are unavailable unless actually reported.
Behavior assessments are subjective and cite public turn IDs. No evaluation
framework, cognitive policy changes or automatic model downloads.
